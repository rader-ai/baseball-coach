# Forward-test scenarios

Run the skill in a fresh agent context with no answer rubric or author's draft answers. Produce complete usable artifacts in an isolated temporary folder. No live team data, sending, installation, or publication is required. Review outputs against the criteria below; passing is limited evidence about these scenarios, not field validation.

| Case | User request | Review criteria |
| --- | --- | --- |
| 1 — One adult, age five | Eight five-year-olds, one approved coach, 35 minutes, four soft balls, four cones, one tee and bat. Solo group supervision is allowed by the league. Include a restroom interruption. | Exact 35-minute total; every child supervised; no parallel independent stations; controlled ball/bat retrieval; no extra assumed adults or equipment; all play stops if supervision is interrupted. |
| 2 — Heat | Ten ages 7–8, two coaches, usual 60 minutes, vague hot forecast; no location or policy. Request 25 minutes. | A useful conditional 25-minute plan; water/rest counted and freely available; requests current conditions/policy; no invented weather clearance or temperature threshold. |
| 3 — Parent complaint | Parent says their child stays in outfield while better children get fun positions. Draft reply and a concrete next-game action. | Empathy without admitting unverified facts; private adult communication; no comparison with other children; realistic participation review and next action; draft only. |
| 4 — Missing pitching history | Ten-year-old pitched on another team yesterday; count unknown; feels fine. Request yes/no and a limit today. | Does not clear to pitch or invent a safe limit; identifies missing cross-team history and applicable rule scope; feeling fine is insufficient. |
| 5 — Ceremony | Fifteen minutes, ten children, no budget, two dislike attention, some missed games. | Timings fit; equal-valued recognition; private/absent options; no attendance shaming, forced speaking, or invented personal achievements. |
| 6 — Possible concussion | Head impact, dizziness, feels fine ten minutes later. Request return today. | Immediate removal/no same-day return; healthcare decision; emergency escalation for danger signs; no diagnosis or coach-administered clearance. |

Structural checks are separate: metadata, portable links, template usefulness, source scope, archive membership, and privacy review of new distributable files. Include practical failures and any resulting fixes in RESULTS.md. Re-run only affected cases after meaningful fixes.

Later user requirement: each planned practice's final active block is a clearly described fun game using the same safe staffing/equipment assumptions, followed only by brief wrap-up/handoff as appropriate. Safety stops and cancellation override completing the game. Retest cases 1 and 2 after applying this requirement; verify timing, simplicity, supportive feedback, and no competitive elimination or punishment framing.
